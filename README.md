# UIPA website design

A homepage and public-request browsing design for discussion with Code with Aloha.

Open `index.html` for the homepage or `requests.html` to browse requests. No installation is needed. For GitHub Pages, publish this folder from the repository root.

Request data is a saved September 28, 2026 snapshot from [UIPA.org](https://uipa.org/requests/), not a live feed. Search and filters work locally. This preview does not submit requests or create accounts.

The UX audit is private and is not included in this repository.
